# SmartCart Customer Segmentation

## 📌 Project Overview
SmartCart Customer Segmentation is a machine learning project that focuses on grouping customers based on their purchasing behavior using **unsupervised learning techniques**.  
The project helps businesses understand different customer types and design **targeted marketing strategies**.

---

## 🎯 Objectives
- Analyze customer purchasing behavior
- Perform data preprocessing and feature scaling
- Apply clustering algorithms for segmentation
- Identify meaningful customer groups
- Support business decision-making through insights

---

## 🧠 Machine Learning Approach
- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Feature scaling
- Unsupervised Learning:
  - K-Means Clustering
  - Agglomerative Clustring
- Cluster evaluation and interpretation

---
